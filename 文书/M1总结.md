## 三、SwiftData 数据模型

### VaultItem（密码条目）
- `id`（唯一标识）、`title`（标题）、`website`（网址）
- `username`（用户名）、`notePreview`（备注摘要）、`iconName`（图标）
- `secretRef`（Keychain 引用）、`isFavorite`（收藏）、`isDeleted`（删除标记）
- `createdAt` / `updatedAt` / `lastUsedAt` / `deletedAt`（时间戳）
- 关联：`group`（所属分组，多对一）、`tags`（标签，多对多）

### VaultGroup（分组）
- `id`、`name`、`colorHex`、`sortOrder`
- `items`（关联的条目，一对多）

### VaultTag（标签）
- `id`、`name`、`colorHex`

## 四、VaultRepository 仓库层

基于 `@Observable` 宏的内存数据仓库，提供以下操作：

| 功能 | 方法 |
|------|------|
| 条目 CRUD | `createItem` / `updateItem` / `toggleFavorite` |
| 分组管理 | `createGroup` / `updateGroup` / `deleteGroup` |
| 标签管理 | `createTag` / `updateTag` / `deleteTag` |
| 回收站 | `moveToTrash` / `restoreFromTrash` / `permanentlyDelete` |
| 搜索过滤 | `filteredItems`（标题/网址/用户名/备注，大小写不敏感） |
| 数据查询 | `allItems` / `favoriteItems` / `trashedItems` / `items(for:)` |

## 五、SwiftUI 视图

### 主窗口 VaultWindowView
- `NavigationSplitView` 三栏布局
- `NavigationItem` 枚举支持全部项目 / 收藏 / 回收站 / 分组(id) / 标签(id) 五种导航
- 侧栏宽度 180-300pt，列表 280-500pt，详情自适应
- Sheet 弹出编辑器

### 侧栏 SidebarView
- 导航项：全部项目 / 收藏 / 回收站
- 分组/标签通过 `NavigationItem.group(id)` / `.tag(id)` 精确导航
- 分组列表（右键重命名/删除）+ 新建分组（Sheet，解决中文 IME 崩溃）
- 标签列表（右键重命名/删除）+ 新建标签（Sheet，解决中文 IME 崩溃）

### 条目列表 ItemListView
- 搜索框（实时过滤）
- 条目行：图标 + 标题 + 用户名 + 分组名
- 右键菜单：收藏/移到回收站
- 滑动操作：删除（普通模式）→ 移到回收站
- 底部工具栏：新建按钮 + 条目计数
- **回收站模式**：图标变为 🗑，左滑恢复，右滑永久删除，底部按钮变为清空回收站

### 条目详情 ItemDetailView
- 头部：大图标 + 标题 + 网址 + 收藏按钮
- 字段区：用户名/密码（掩码显示）+ 复制按钮
- 备注区、标签区
- 元数据：分组、创建时间、更新时间
- 底部：移到回收站 / 永久删除（根据 `isDeleted` 状态切换）
- 已删除条目隐藏编辑按钮

### 条目编辑器 ItemEditorView
- 表单：标题 / 网址 / 用户名 / 密码（SecureField）/ 备注 / 分组选择 / 标签多选
- 支持新建和编辑两种模式
- 保存按钮在标题为空时禁用
- 收藏模式下新建自动标记为收藏（`startAsFavorite` 参数）

### 回收站 TrashView
- 已删除条目列表（显示删除时间）
- 滑动恢复/永久删除
- 多选批量操作
- 清空回收站确认对话框（`pendingDeleteIDs` 避免选中状态被清空）

## 六、UI 问题修复记录

| 问题 | 根因 | 修复 |
|------|------|------|
| 点击分组/标签后显示全部条目 | `NavigationLink` 全部指向 `.allItems` | 引入 `NavigationItem.group(id)` / `.tag(id)` 精确导航 |
| 回收站无法永久删除 | 列表滑动删除调用的是 `moveToTrash` | 回收站模式下右滑改为 `permanentlyDelete`，左滑 `restoreFromTrash` |
| 确认对话框选中状态被清空 | `List(selection:)` 弹出 dialog 时清除选中 | 使用 `pendingDeleteIDs` 在弹窗前保存选中 ID |
| 中文输入法崩溃 | `.alert` + `TextField` + 中文 IME 系统 Bug | 替换为 `.sheet` + 独立 `CreateGroupSheet` / `CreateTagSheet` |
| 编辑表单无密码输入框 | 遗漏 | 新增 `SecureField("密码")` |
| 收藏模式下新建未自动收藏 | 无此功能 | `VaultItemDraft.isFavorite` + `startAsFavorite` 参数链 |

## 九、技术要点

1. **SwiftData + @Model 宏**：自动生成持久化代码，支持关系定义
2. **@Observable 宏**：替代 ObservableObject，简化 SwiftUI 数据绑定
3. **NavigationSplitView**：macOS 原生三栏布局
4. **PBXFileSystemSynchronizedRootGroup**：Xcode 26 新特性，自动同步文件系统无需手动管理文件引用
5. **Swift Testing**：使用 `#expect` 宏替代 XCTest 断言
6. **NavigationItem 枚举**：支持分组/标签精确导航，避免全部指向 `.allItems`

## 十、M2 阶段准备

M1 阶段为后续工作奠定了数据骨架。M2 将在此基础上接入：

- `AuthService`（LocalAuthentication：Touch ID / Apple Watch / 本机密码）
- `CryptoService`（AES-GCM 加密/解密）
- `KeychainStore`（Keychain 存储敏感密文）
- 真实密码的创建、查看、复制、编辑
- 复制后剪贴板自动清空

M1 的 VaultRepository 接口已为 M2 预留扩展点，`secretRef` 字段将在 M2 中接入真实的 Keychain 引用。
