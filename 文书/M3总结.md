## 三、功能详细设计

### 3.1 密码生成器（PasswordGenerator）

```swift
struct PasswordGenerator: Sendable {
    struct Options: Sendable {
        var length: Int = 16              // 4-64
        var includeUppercase: Bool = true
        var includeLowercase: Bool = true
        var includeDigits: Bool = true
        var includeSymbols: Bool = true
    }

    enum Strength: String, Comparable {
        case veryWeak = "非常弱"   // 熵 < 28 bits
        case weak = "弱"          // 熵 28-36
        case fair = "一般"        // 熵 36-60
        case strong = "强"        // 熵 60-80
        case veryStrong = "非常强" // 熵 ≥ 80
    }

    static func generate(options: Options) -> String
    static func strength(of password: String) -> Strength
    static func entropyBits(of password: String) -> Double
}
```

**安全特性**：
- 确保生成的密码包含所有选中的字符类型（后处理保证，非概率依赖）
- 使用 `Int.random(in:)` 密码学安全随机源
- 强度评估基于 Shannon 熵公式：`entropy = length × log2(poolSize)`

### 3.2 密码生成器 UI（PasswordGeneratorView）

- 以 Sheet 形式从 ItemEditorView 密码输入框旁的魔法棒按钮打开
- 实时显示生成密码及强度指示条（红→橙→黄→绿→蓝）
- 可调选项：长度 Stepper（4-64）、大写/小写/数字/符号 Toggle
- "重新生成"和"复制密码"按钮
- "使用"按钮将密码回填到编辑器

### 3.3 加密备份（BackupService）

#### 备份格式

```swift
struct BackupRecord: Codable {
    var version: Int              // 备份格式版本号（当前 = 1）
    var createdAt: Date
    var appVersion: String
    var items: [BackupItem]       // 含 EncryptedSecret 的完整条目
    var groups: [BackupGroup]
    var tags: [BackupTag]
}
```

- 文件扩展名：`.pwd`
- UTI 类型：`com.pwdsafe.pwd`
- 格式：JSON（`.prettyPrinted` + `.sortedKeys`）

#### 导出流程

1. 用户点击菜单 → "导出加密备份..."
2. 触发 `authService.authenticate()` 认证
3. `BackupService.exportBackup()` 遍历所有条目（含回收站）
4. 从 Keychain 读取每个条目的 `EncryptedSecret`（密文不解密，原样导出）
5. 序列化为 JSON → `BackupDocument` → `fileExporter` 保存到用户指定路径

#### 导入流程（含去重）

1. 用户点击菜单 → "导入加密备份..."
2. `fileImporter` 选择 `.pwdsafe-backup` 文件
3. 触发 `authService.authenticate()` 认证
4. `BackupService.readBackup()` 解析 JSON → 版本校验
5. `BackupService.importBackup()` 按 UUID 去重：
   - 分组/标签：已存在则跳过，不存在则保留原始 UUID 创建
   - 条目：已存在且未删除则跳过；已存在且已删除则自动还原；不存在则新建

**安全考量**：
- 密文原样导出/导入，不解密重加密，保持与原 VaultKey 的绑定关系
- 跨设备恢复需要同时迁移 VaultKey（M4 计划）
- `BackupGroup`/`BackupTag` 含 `colorHexes` 字段确保混合配色不丢失

### 3.4 设置页（SettingsView）

基于 `@AppStorage` 持久化的四项设置：

| 设置项 | AppStorage Key | 默认值 | 可选值 |
|--------|---------------|--------|--------|
| 认证策略 | `authPolicy` | `session5min` | 每次认证 / 5分钟内免重复认证 |
| 剪贴板清除 | `clipboardTimeout` | `seconds30` | 15秒 / 30秒 / 60秒 / 不清除 |
| 自动锁定 | `autoLockTimeout` | `minute5` | 1分钟 / 5分钟 / 15分钟 / 永不 |
| 回收站清理 | `trashAutoCleanup` | `never` | 不自动 / 30天 / 90天 |

UI 分为"安全"和"通用"两个 Tab，每个 Tab 内使用 `Form` + `Picker`。

### 3.5 编辑器密码生成器集成

- ItemEditorView 密码输入框右侧新增魔法棒按钮
- 点击弹出 PasswordGeneratorView Sheet
- "使用"后密码回填到编辑器 `@State password` 字段

### 3.6 VaultRepository 新增方法

| 方法 | 功能 |
|------|------|
| `exportBackup() async throws → BackupRecord` | 认证后导出完整备份 |
| `importBackup(from url:) async throws` | 认证后从文件导入备份 |
| `storeSecretData(_:for:) throws` | 将密文写入 Keychain（供导入使用） |
| `appendItem(_:)` | 将 VaultItem 加入列表（供导入使用） |
| `appendGroup(_:)` | 将 VaultGroup 加入列表（保留 UUID） |
| `appendTag(_:)` | 将 VaultTag 加入列表（保留 UUID） |
| `lock()` / `unlock()` | 锁定/解锁保险库，支持启动认证与闲置自动锁定 |

## 四、UI/UX 增强（M3 后期迭代）

### 4.1 侧栏改进

- **折叠分组/标签**：分组与标签 Section 新增 `▶`/`▼` 折叠按钮（右侧），与行内齿轮编辑按钮垂直对齐
- **编辑按钮**：每个分组/标签行右侧新增齿轮图标按钮，点击弹出编辑 Sheet 修改名称和颜色
- **配色混合选择器**（`ColorMixPicker`）：
  - 左侧选中区：配色以堆叠遮挡排列，鼠标移入后展开为横向排列（`spacing` 动画过渡），每色带 ✓/✕ 提示标志
  - 右侧待选区：未选配色逐个排列，鼠标移入显示 `+` 提示
  - 选中区与待选区由细竖线分隔
  - 点击添加/移除配色使用 `matchedGeometryEffect` 实现平滑飞行动画
  - 选中配色列表持久化到 `colorHexes` 字段（非仅保存混合结果）
  - 8 色调色板使用高饱和值：`#FF3B30`/`#FF9500`/`#FFCC00`/`#34C759`/`#007AFF`/`#AF52DE`/`#32ADE6`/`#8E8E93`

### 4.2 工具栏重构

- **按钮顺序**：新建(+) → 编辑(✏️) → 删除操作 → 设置(⋯)
- **普通模式**：新建 / 编辑 / 移到回收站(🗑) / 清空条目到回收站(🗑✕) / 设置
- **回收站模式**：恢复(↩) / 永久删除(🗑) / 清空回收站(🗑✕) / 设置
- 废弃 `plus.circle` 改为纯 `plus`，废弃 `trash.slash` 统一为 `trash`
- 编辑按钮增加权限验证（共享 `.viewSecret` 会话缓存）
- 回收站恢复操作后自动清空详情视图选中状态

### 4.3 详情视图改进

- **统一字段卡片**：用户名/邮箱/手机/密码/备注/标签合并为单一 `RoundedRectangle` 卡片，各项由 `Divider` 细线分隔
- **图标颜色跟随分组**：钥匙图标颜色使用 `item.group?.colorHex`，无分组时显示灰色
- **交互式字段**：
  - 鼠标悬停显示灰色背景阴影
  - 左键自动拷贝，文字变为「已拷贝」持续 1 秒（带缩放+透明度过渡动画）
  - 右键菜单：复制内容 / 放大显示（弹窗大字体展示，支持文本选择）
- **密码自动隐藏**：鼠标移出字段卡片或点击密码文本时自动恢复遮挡

### 4.4 启动认证与自动锁定

- **锁屏界面**：启动后显示居中锁图标 + "点击解锁"按钮，点击触发 Touch ID / 本机密码验证
- **自动锁定**：通过 `@Environment(\.scenePhase)` 监听前后台切换，回到前台时根据设置的超时时间（1/5/15分钟）自动锁定
- 锁屏状态通过 `repository.isLocked` 统一管理

### 4.5 备份导入去重

- 导入时按 UUID 去重：已存在且未删除的条目跳过，已存在且已删除的条目自动还原
- 分组/标签创建时保留备份中的原始 UUID（通过 `appendGroup`/`appendTag`）
